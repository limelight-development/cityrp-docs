    Tables

    SharedLITECHAR_ACCESSORY_SLOTSSource ☍

    Every CityAccessories Type -- one dropdown per slot in the editor.

    SharedLITECHAR_EXCLUDED_ITEMSSource ☍

    Developer exclusion table. Anything listed here is invisible to every dropdown in this system (Model/Accessories/Bodygroup Accessories/Extras) and is also re-rejected server-side at save time and activation time, regardless of what a client sends. Extend by adding one line -- no other code changes required.

    SharedLITECHAR_SLOT_TIERSSource ☍

    Reserves slots off the END of the range for players who pass check, working backward through the list -- e.g. with the defaults below and LITECHAR_SLOTS = 10: the last 5 slots (6-10) require HasMembership, then the next 2 slots counting backward (4-5) require IsMember. Slots 1-3 stay unrestricted. Reorder/add/resize entries freely; both ply:IsMember() and ply:HasMembership() are defined shared (core/metatables/sh_player.lua) so this works identically client- and server-side.

    SharedLITECHAR_TEAM_MODEL_CATEGORIESSource ☍

    Groups jobs (TEAM_* constants) that should share one pooled "Team Character" model list -- e.g. a Police Officer and Police Chief can each pick from either job's own team models.
