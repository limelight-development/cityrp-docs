    cityrp.limits

    Per-player spawn and ownership limit overrides. Each type is a cityrp.layers stack published to a cityrp.network var; every write lives in sv_playerlimits.lua. Named for load order: the Register calls below need sh_network.lua first.

    Sharedcityrp.limits:CanSet(ply, name) → booleanSource ☍

    Check whether a player is allowed to adjust a limit type on someone else. Moderator S2 and above get every type; Assistants and Event Managers only the team ones. Server-side only: HasAccess is accurate on the client for LocalPlayer alone.

    Parameters

    • plyPlayerThe player running the command.
    • namestring|LIMIT_TYPEThe limit type, or its id/alias.

    Returns

    1. booleanTrue if they may adjust this type.

    Apply the light limit to the sandbox light and lamp counters, where the tools actually check. Never lifts a counter above its own sbox_max*: the two share one limit type, so a light override must not become a lamp allowance.

    Sharedcityrp.limits.LIGHT_COUNTERSSource ☍

    Sandbox counters a light limit applies to, each with the ConVar sandbox would have capped it by. The light and lamp tools are unlocked together (cityrp.BlockedTools, GM:CanTool), so they are limited together, but they keep their own sbox ceilings.
