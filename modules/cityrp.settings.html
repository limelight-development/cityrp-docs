cityrp.settings

Client-side settings registry for the CityRP settings panel. Plugins register categories and individual settings here; the player_settings plugin renders them in a unified GUI. Existing ConVars, cookies, and chat commands are wired through rather than replaced.

Functions

cityrp.settings.CanSeeStaffSettingsSource ☍

Returns whether the local player can see staff-only settings.

Returns:

  1. boolean True when the player is a trial mod or above.
cityrp.settings.CloseSource ☍

Closes the settings panel when it is open.

cityrp.settings.GetCategoryEntriesSource ☍

Returns settings for a category that are visible to the local player.

Parameters:

  • categoryId string Category identifier.

Returns:

  1. CityRPSettingsEntry[] Visible settings for the category.
cityrp.settings.GetVisibleCategoriesSource ☍

Returns categories visible to the local player, sorted by order then name.

Returns:

  1. CityRPSettingsCategory[] Visible categories.
cityrp.settings.OpenSource ☍

Opens the settings panel, creating it when needed.

cityrp.settings.RegisterSource ☍

Registers a single setting row in the unified settings panel.

Parameters:

  • entry CityRPSettingsEntry Setting definition.

Returns:

  1. boolean False when the id was already taken.
cityrp.settings.RegisterCategorySource ☍

Registers a sidebar category for grouping settings.

Parameters:

  • id string Unique category identifier.
  • name string Display name shown in the sidebar.
  • order number? Sort order (lower appears first).
  • staffOnly boolean? When true, only trial mods and above see this category.
cityrp.settings.ToggleSource ☍

Toggles the settings panel open or closed.
