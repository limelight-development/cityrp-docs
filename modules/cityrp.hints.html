cityrp.hints

Clientside Hints System.

Functions

cityrp.hints.CycleSource ☍

Gets the current hint text to display for a cycling group, based on elapsed time.

Parameters:

  • class string The cycling group identifier.

Returns:

  1. string? The current hint text, or nil if the group has no hints registered.
cityrp.hints.GetSource ☍

Gets whether a hint is currently enabled.

Parameters:

  • key string The hint identifier.

Returns:

  1. boolean? Whether the hint is enabled, or nil if the hint has never been set.
cityrp.hints.NameSource ☍

Gets the cookie name used to persist a hint's enabled state.

Parameters:

  • key string The hint identifier.

Returns:

  1. string The cookie name for the hint.
cityrp.hints.RegisterSource ☍

Registers a hint so it can be toggled from the F1 hints menu.

Parameters:

  • key string Unique hint identifier.
  • name string? Display name shown in the hints menu, derived from key if omitted.
  • desc string? Description shown under the hint's checkbox.
cityrp.hints.RegisterCyclingSource ☍

Registers one or more hints to cycle through for a given class.

Parameters:

  • class string The cycling group identifier.
  • hint string|number The first hint to add, or the per-hint cycle time in seconds (in which case the actual hint text follows in ...).
  • string Additional hint strings to cycle through.
cityrp.hints.SetSource ☍

Sets whether a hint is enabled and persists the choice to a cookie.

Parameters:

  • key string The hint identifier.
  • enabled boolean Whether the hint should be enabled.
