table.FullCopySource ☍

Create a deep copy of a table, copying vectors and angles by value. table.Copy and table.copy both leave userdata as references, so a copy made with either still shares its vectors and angles with the original. That matters for anything that mutates them in place, which is why the SWEP Construction Kit weapons each used to carry their own version of this. Entities are still copied by reference. Do not use on a table that contains itself, it will recurse forever.

Parameters:

  • tab table? The table to copy.

Returns:

  1. table? The copied table, or nil if no table was given.
