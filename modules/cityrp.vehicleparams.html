Runtime vehicle script / VehicleParams helpers. Shared foundation for the vehiclescript editor and future item-meta vehicle mods.

cityrp.vehicleparams.ParseKeyValuesSource ☍

Parse a Valve KeyValues document into an ordered node tree. Nodes are {key = string, value = string} or {key = string, children = node[]}. Order, duplicate keys and blocks the schema knows nothing about are all preserved, so a parse/serialize round trip only reformats — it never drops content.

Parameters:

  • text string? Raw script contents.

Returns:

  1. table[]|nil Ordered root nodes, or nil when the document is malformed.
cityrp.vehicleparams.RegisterModifierSource ☍

Register a named runtime modifier used by item meta / future mod plugins. Re-registering the same id replaces the previous definition (hot-reload safe).

Parameters:

  • id string Stable modifier id (e.g. "springs", "turbo", "engine_upgrade").
  • apply fun(params: table, context: table) Mutates params in place.
  • priority number? Lower runs first. Defaults to 100.

cityrp.vehicleparams.SerializeKeyValuesSource ☍

Serialize editable (MPH) params into a Valve KeyValues vehicle script. With sourceScript, the original document is reformatted and only schema-owned keys are rewritten: "Vehicle_Sounds", wheel materials, DustCloud and any other key the editor does not model keep their original values. Without it (or when the source will not parse) only the "Vehicle" physics block can be emitted.

Parameters:

  • params table Editable params.
  • header string? Optional comment header line.
  • sourceScript string? Contents of the vehicle's original script file.

Returns:

  1. string
  2. boolean Whether sourceScript was parsed and carried through.

cityrp.vehicleparams.AxleFieldSchemaSource ☍

Per-axle field template (script Wheel / Suspension nested blocks). Axle 1 is usually the front, axle 2 the rear.

cityrp.vehicleparams.FieldSchemaSource ☍

Schema describing editor sections and KeyValues export mapping. Axle sections are generated per axle at runtime from this template. help is shown in the editor. impact is 1–10 (how much a change usually feels).

cityrp.vehicleparams.modifiersSource ☍

Registered runtime modifiers keyed by id. Future plugins call RegisterModifier; item meta collectors resolve by id.

cityrp.vehicleparams.MPH_TO_HUSource ☍

Hammer units per second per mile-per-hour. Inverse of Entity:LLSpeed / Photon_AdjustedSpeed: HU/s * (3600 / 63360) = MPH. GetVehicleParams returns engine speeds in HU/s. Since 2021, SetVehicleParams uses the same units (not MPH). Vehicle .txt scripts still store MPH.
