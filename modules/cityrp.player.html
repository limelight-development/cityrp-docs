cityrp.player

Server-side player library: name validation, player lookup/resolution, networked player-data replication, database save queries, and the per-tick player update loop.

Functions

cityrp.player.getSource ☍

Finds a player by exact UserID, a STEAM_ SteamID, or a case-insensitive partial name match.

Parameters:

  • name string|nil The search term. STEAM_-prefixed values are delegated to cityrp.player.getid.

Returns:

  1. boolean|Player The single matched player, or false if none or more than one matched.
  2. boolean|table<number, Player> The list of matched players, or false if none matched.
cityrp.player.getDataKeyValuesSource ☍

Builds a MySQL-escaped, comma-separated column list and matching value list for a player's saved fields. Intended for building an INSERT statement (see cityrp.player.getDataUpdateQuery for UPDATE).

Parameters:

  • player Player The player to build the key/value lists for.

Returns:

  1. string The comma-separated column names.
  2. string The comma-separated, quoted and escaped values, in the same order as keys.
cityrp.player.getDataUpdateQuerySource ☍

Builds an UPDATE query saving a player's data, guarded by an optimistic _TimePlayed check. Saves a reduced column set on build/event servers or when saving is disabled.

Parameters:

  • player Player The player to build the update query for.

Returns:

  1. string The full UPDATE ... WHERE SQL statement.

cityrp.player.resolveTargetSource ☍

Resolve a player from a search term (name, UserID, or SteamID). Notifies the caller on failure unless silent is true. Prefer this over hand-rolling cityrp.player.get error handling in commands.

Parameters:

  • caller Player The player requesting the lookup.
  • arg string Search term.
  • silent boolean? If true, do not notify on failure.

Returns:

  1. Player|nil The resolved player, or nil.
  2. Player[]|nil When silent and ambiguous: the list of matches.

cityrp.player.saveDataAllSource ☍

Bulk-saves every initialized player's data with a single multi-row INSERT ... ON DUPLICATE KEY UPDATE query. Saves a reduced column set on build/event servers or when saving is disabled.

Sets a player's local player variable and, if it changed, networks it to that client only.

Parameters:

  • value any The value to set. Coerced to the type's default ("", 0, false, etc) if nil.
